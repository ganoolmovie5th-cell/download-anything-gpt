Apakah semua website didukung?

File publik langsung dan file yang tercantum pada HTML didukung. Situs yang membutuhkan JavaScript, login, cookie, atau ekstraktor khusus seperti TikTok tidak dijamin. Video YouTube belum didukung pada versi Vercel-only; hasilnya menampilkan penjelasan, bukan tautan unduhan palsu. DRM dan penggabungan streaming HLS/DASH tidak didukung.

Bisa memilih kualitas dan mengubah format?

Kualitas ditampilkan jika sumber menyediakan beberapa varian, misalnya gambar srcset atau video berlabel 360p/1080p. “Asli” berarti sumber tidak memberi label kualitas. Aplikasi tidak melakukan konversi, upscale, atau membuat varian baru. Urutan mengikuti angka label sumber, bukan penilaian kualitas visual.

Kenapa file besar dibuka di sumber?

Unduhan lewat server dibatasi 3 MB agar sesuai batas Vercel. “Buka sumber” menuju URL asli; browser bisa memutar atau menampilkan file. Gunakan menu simpan browser. Sumber dapat menolak akses atau menonaktifkan unduhan.
